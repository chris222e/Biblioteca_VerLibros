#📚 Biblioteca_VerLibros


📖 Sistema web de biblioteca desarrollado en PHP / CodeIgniter 4, que permite registrar y visualizar libros de forma sencilla, rápida y organizada.

```🎯 Funcionalidades del sistema

-📖 #Registro de libros en la base de datos
-👀 #Visualización de libros registrados
```

```🛠️ Tecnologías utilizadas

-💻 #PHP (CodeIgniter 4)
-🗄️ #MySQL
-📦 #Composer
-🌐 #HTML5
-🎨 #CSS3
-⚙️ #JavaScript
-🧩 #SB Admin 2
```

```⚙️ Instalación del proyecto
1️⃣ Clonar el repositorio
git clone https://github.com/chris222e/Biblioteca_VerLibros.git
2️⃣ Instalar dependencias
composer install
3️⃣ Configurar plantilla SB Admin 2
📁 Copiar la carpeta:
vendor → public/
4️⃣ Configurar variables de entorno
📄 Copiar el archivo:
.env.example → .env
✏️ Luego editar:
CI_ENVIRONMENT = development
```
```
5️⃣ Configuración de base de datos

🗄️ Editar el archivo .env:

-database.default.hostname = localhost
-database.default.database = sytemB
-database.default.username = root
-database.default.password =
-database.default.DBDriver = MySQLi
-database.default.DBPrefix =
-database.default.port = 3306
```


```6️⃣ Migraciones

⚙️ Ejecutar:

php spark migrate
```

```
7️⃣ Ejecutar el proyecto

🚀 Levantar servidor:

php spark serve
```
```

🌐 Abrir en el navegador:

http://localhost:8080

```
